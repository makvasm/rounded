# Айдентика ROUNDED

Этот документ описывает визуальный язык темы так, чтобы будущие изменения его
сохраняли. Значения в нём сняты с файлов репозитория. Если правило расходится
с файлом, верным считается файл: исправьте документ и укажите причину в коммите.

Прочитайте документ перед изменением любого SVG, цветовой схемы или
декорации. Перед коммитом пройдите по [контрольному списку](#контрольный-список-изменения).

## 1. Характер

ROUNDED — мягкая, плоская и спокойная тема. Ниже её признаки по степени
важности:

1. **Крупные плавные углы.** У окон, диалогов, подсказок и фонов апплетов
   угол 24 px. Это не дуга окружности, а сглаженная кривая, похожая на
   суперэллипс.
2. **Плоские поверхности без обводок.** Поверхности отделяются тоном,
   полупрозрачностью и мягкой тенью, а не линиями.
3. **Один акцент.** Акцентный цвет появляется только там, где есть
   состояние: фокус, выделение, внимание, заполненная часть шкалы. Покой
   всегда монохромный.
4. **Кнопки заголовка в кольцах.** Глифы кнопок окна заключены в контурные
   круги.
5. **Варианты темы.** COLOR следует палитре пользователя. DARK —
   фиксированная тёмная тема с фирменным градиентом
   «маджента → синий».

Чего в ROUNDED нет: обводок по контуру, бликов и объёмных градиентов на
кнопках, декоративной анимации, иконок приложений, шрифтов и курсоров.
Иконки приложений (меню, панель задач, окна), шрифты, курсоры и стиль
приложений берутся из Breeze и системных настроек. Свои у темы только
монохромные значки панели и системного лотка (раздел 8.1).

## 2. Два варианта

| | COLOR (`ROUNDED-COLOR`, схема `ROUNDED`) | DARK (`ROUNDED-DARK`, схема `ROUNDEDDARK`) |
| --- | --- | --- |
| Откуда цвета SVG | классы `ColorScheme-*` и `currentColor`, то есть палитра пользователя | цвета зашиты в SVG и совпадают с `ROUNDED-DARK/colors` |
| Акцент в SVG | `ColorScheme-Highlight` | градиент `#a22f66 → #1b77a0` или сплошной `#a22f66` |
| Кольцо фокуса | `ColorScheme-Highlight` | `#d28cca` |
| Выделение (`viewitem`) | Highlight с горизонтальным затуханием непрозрачности 1 → 0.2 | градиент `#a22f66 → #1b77a0` при opacity 0.8 |
| Декорация в глобальной теме | Breeze, следует палитре | Aurorae `ROUNDED-DARK` |
| Иконки приложений | `breeze` | `breeze-dark` |
| Значки панели и лотка (`icons/`) | только `ColorScheme-*` | `#eff0f1` и фирменные цвета DARK |
| Фон заставки | `#eff0f1` | `#31363b` |

**Правило COLOR.** В `ROUNDED-COLOR` не появляется ни одного нового
жёстко заданного цвета для видимых частей; используются только роли
`ColorScheme-*`. Исключения — служебные метки (`hint-*`, красный `#ff0000`,
маджента, зелёный в маркерах полей) и чёрные тени.

**Правило DARK.** Каждый цвет в SVG `ROUNDED-DARK` должен быть из палитры
раздела 4. Если меняете роль в `ROUNDEDDARK.colors`, синхронно измените
`plasma/desktoptheme/ROUNDED-DARK/colors`; чекер требует, чтобы они совпадали.

## 3. Форма

### Шкала радиусов

| Уровень | Радиус | Тип кривой | Где используется |
| --- | --- | --- | --- |
| Окно / поверхность | 24 px | сглаженный угол: кубическая кривая с ручками 20/24 (≈0.83 радиуса) | `dialogs/background`, `widgets/background`, `widgets/tooltip`, Aurorae `decoration` (угол, маска, тень) |
| Панель | 12 px | дуга окружности (ручка 0.554) | `widgets/panel-background` |
| Кнопка | 7 px | дуга; кольцо фокуса — дуги 7/5 | `widgets/button`, кнопки заголовка (подложка `rx=6` на холсте 22) |
| Пункт меню | 6 px | сглаженный угол (`C 2 2 6 2`) | `widgets/menubaritem` |
| Поле ввода | 4 px | дуга; кольца 4/3 и 4/2 | `widgets/lineedit` |
| Задача на панели | 3 px | дуга; контур свёрнутой задачи 3/2 | `widgets/tasks` |
| Элемент списка | ≈2.5 px | дуга | `widgets/viewitem` |
| Круглые элементы | полный круг | — | `radiobutton`, ручки `slider` и `switch`, кнопки заголовка |

Правила:

- **Вложенный элемент скругляется меньше внешнего.** Окно (24) > панель
  (12) > кнопка (7) > поле (4) > задача (3). Новый элемент получает
  ступень этой шкалы, а не промежуточное значение.
- **Сглаженный угол (суперэллипс) — только у крупных поверхностей
  (24 px) и пунктов меню.** Малые элементы используют обычную дугу; на
  размерах 3–7 px разница всё равно не видна.
- **Кольца строятся как разность двух дуг** (`A R … A r`), чтобы при
  растяжении nine-slice толщина оставалась постоянной: 2 px у фокуса,
  1 px у наведения и контура.
- **Канавки** (`slider`, `switch`, `scrollbar`) — капсулы с радиусом,
  равным половине толщины.

### Поля и плотность

| Элемент | Отступы содержимого (`hint-*-margin`) |
| --- | --- |
| Диалог | 12 px по бокам, 12 сверху и снизу |
| Подсказка | 14 px |
| Фон апплета | 24 px |
| Панель | 2 px в тонком режиме, 8 px в толстом (`thick-hint-*`) |
| Кнопка | 2–3 px |
| Поле ввода | 1–2 px |

Тема просторная внутри поверхностей и плотная внутри элементов управления.
Не уменьшайте внутренние отступы диалогов и апплетов ради плотности.

## 4. Цвет

### Нейтральные тона

| Роль | ROUNDED (светлая) | ROUNDEDDARK |
| --- | --- | --- |
| Окно, заголовок, панель | 239,240,241 `#eff0f1` | 49,54,59 `#31363b` |
| Неактивный заголовок Aurorae | `#e3e5e7` | `#272b2f` |
| Вид (списки, поля) | 255,255,255 | 43,48,52 |
| Кнопка | 255,255,255 | 68,76,83 `#444c53` |
| Основной текст | 35,38,39 | 239,240,241 |
| Вторичный текст (`ForegroundInactive`) | 108,107,106 | 189,195,199 |
| Complementary (тёмные панели) | 49,54,59 / текст 239,240,241 | то же |

Тон неактивного окна темнее активного примерно на одну ступень. Это
основной сигнал фокуса окна наряду с цветом заголовка.

### Акцент

- **Фирменный акцент схем — фиолетовый 158,83,150 (`#9e5396`).** Это
  `Selection/BackgroundNormal` в обеих схемах, `DecorationFocus` в светлой
  схеме и `Color0` в Konsole.
- **В тёмной схеме фокус светлее: 210,140,202 (`#d28cca`).** Исходный
  фиолетовый давал на тёмном фоне меньше 3:1.
- **Фирменный градиент DARK:** `#a22f66` (маджента) → `#1b77a0` (синий),
  слева направо, всегда в этом порядке. Применяется в выделении, заполнении
  шкал, слайдере, переключателе, вкладках, задачах и часах. Сплошной
  `#a22f66` используется там, где градиент не читается (точки, задача,
  требующая внимания).
- **COLOR не задаёт свой оттенок акцента.** В SVG стоит
  `ColorScheme-Highlight`, а значение в таблице стилей по умолчанию
  (`#3daee9`) — только запасное. Не заменяйте его фиолетовым: COLOR обязан
  следовать палитре.

### Семантические цвета

| Значение | Цвет | Где допустим |
| --- | --- | --- |
| Опасное действие | `#da4453`, нажатие `#b52f3c`, крестик `#fcfcfc` | только наведение и нажатие кнопки закрытия Aurorae |
| Ошибка / отрицательное | `ForegroundNegative` схемы | текст, через роль схемы |
| Внимание (задача) | Highlight (COLOR) / `#a22f66` (DARK) | задача, требующая внимания |

Красный не используется для декора и в спокойном состоянии. Кнопка
закрытия в покое монохромная, как остальные. Чекер это проверяет.

### Непрозрачность поверхностей

| Поверхность | Непрозрачность фона |
| --- | --- |
| Диалоги (`dialogs/background`) | 1.0 |
| Панель, подсказка, фон апплета | 0.8, адаптивная прозрачность включена |
| `opaque/` и `solid/` | 1.0 (варианты Plasma без композитинга/размытия) |

`ContrastEffect` выключен в обоих стилях: стекло без цветового эффекта.
Если меняете это, проверьте текст на пёстрых обоях.

## 5. Глубина

- Тени — только мягкие градиенты от чёрного к прозрачному (`shadow-*`),
  тень диалога и подсказки около 7 px, панели около 3.5 px.
- Нет обводок, внутренних бликов и тиснения. Исключение — контур 1 px
  (цвет текста, 0.55) там, где без него не видна граница элемента
  управления: свёрнутая задача, дорожка и ручка переключателя. Поверхности
  контуром не обводятся.
- Подъём выражается тенью, а не обводкой или более светлым краем.
- Окна Aurorae рисуются без собственной тени (`Shadow=false`); тень даёт
  KWin.

## 6. Язык состояний

Состояние показывается **полупрозрачной заливкой цветом текста** поверх
поверхности. Акцент добавляется только для фокуса, выделения и внимания.
Если меняется только цвет, должна меняться и форма или толщина.

### Шкала тона (Text / `#eff0f1` поверх поверхности)

| Состояние | Задачи | Кнопки заголовка | Элементы списков | Канавки |
| --- | --- | --- | --- | --- |
| Покой | 0.14 | 0 | 0 | 0.2 |
| Наведение | 0.22 | 0.15 | 0.1 | — |
| Нажатие / активное | 0.22 + акцентная полоска у фокуса | 0.28 | 0.2 | — |

Ступени должны оставаться строго возрастающими: покой < наведение ≤ фокус
< нажатие. Для задач это проверяет чекер.

### Особые состояния

| Состояние | Решение | Почему |
| --- | --- | --- |
| Фокус клавиатуры | кольцо 2 px цветом акцента (`button`, `lineedit`, `radiobutton`) | видно без опоры на цвет: появляется новая форма |
| Наведение на поле | кольцо 1 px, Text/`#eff0f1` при 0.35 | слабее фокуса |
| Выделение | заливка акцентом; в COLOR — затухание вправо, в DARK — градиент | |
| Свёрнутая задача | контур 1 px (0.55) без заливки | отличие формой, ≥ 3:1 к панели |
| Переключатель | дорожка-капсула: заливка 0.2 + контур 1 px (0.55); включён — акцент (DARK — фирменный градиент); ручка ButtonBackground с контуром 1 px; наведение/нажатие — тон 0.15/0.28 на ручке; фокус — кольцо 2 px акцентом внутри ручки | граница видна в выключенном состоянии (≥ 3:1); фокус не сливается с включённой дорожкой |
| Внимание | сплошной акцент | |
| Неактивное окно | более тёмный тон рамки и приглушённый заголовок (≥ 4.5:1) | |
| Отключённая кнопка заголовка | непрозрачность 0.5, без смены формы | |

## 7. Декорация окна (Aurorae)

| Параметр | Значение |
| --- | --- |
| Угол | 24 px, сглаженный, как у диалогов |
| Высота заголовка, кнопки | 24 px, интервал 4 px |
| Рамка | 2 px слева, справа и снизу, сплошной тон окна |
| Заголовок | по центру, без тени текста |
| Активный текст | 35,38,39 / 239,240,241 |
| Неактивный текст | 95,98,101 / 166,169,172 |
| Анимация | `Animation=0` (нет подтверждения, что Aurorae учитывает глобальное отключение анимаций) |

**Глифы.** Каждая кнопка — тонкий контурный круг, внутри
которого символ:

| Кнопка | Символ в кольце |
| --- | --- |
| Закрыть | косой крест |
| Развернуть | кольцо меньшего размера |
| Свернуть | точка |
| На всех столах | четыре точки 2×2 |
| Поверх / под всеми | треугольник вверх / вниз |
| Восстановить | два перекрывающихся квадрата (штрих 1.5 px) |

У каждой кнопки пять состояний: active, hover (скруглённая подложка 0.15),
pressed (0.28), inactive (приглушена), deactivated (0.5). Все монохромные,
кроме наведения и нажатия кнопки закрытия: там глиф заменяется сплошным
красным кругом r = 8 с белым крестиком.

Новые кнопки (справка, свернуть в заголовок) рисуются по той же схеме:
кольцо плюс простой геометрический символ, без текста.

## 8. Значки, типографика, движение

### 8.1. Значки панели и системного лотка

Каждый стиль содержит 101 файл в `plasma/desktoptheme/ROUNDED-*/icons/`.
Это не иконки приложений: Plasma берёт их только для системных апплетов
(батарея, сеть, звук, уведомления, буфер обмена, KDE Connect, OSD) и для
значков приложений в лотке (`vlc`, `kmail`, `thunderbird`, `qbittorrent`,
`yakuake` и др.). В меню и на панели задач у тех же приложений остаются
иконки Breeze. Наборы COLOR и DARK совпадают по составу и геометрии и
различаются только цветом.

**Сетка и форма**

| Параметр | Значение |
| --- | --- |
| Холст | 22×22 (`22-22-<имя>`) плюс масштабируемая копия без префикса; единичные 16×16 и 8×8 |
| Границы холста | невидимый прямоугольник 22×22 с `opacity:0.001` в каждом элементе |
| Поле | рисунок в области 2…20 px, по 2 px от края |
| Линия | 1 px, построена заливкой контура, а не `stroke`; концы линий скруглены (дуги r = 0.5) |
| Углы | скругления 1.5–2.7 px; острых прямых углов у корпусов нет |
| Стиль | контурный; сплошная заливка только у мелких деталей и у знаков-индикаторов |
| Градиенты, тени | нет |

**Цвет и состояния**

| Значение | COLOR | DARK | Примеры элементов |
| --- | --- | --- | --- |
| Основной рисунок | `ColorScheme-Text` | `#eff0f1` | почти все |
| Неактивная часть шкалы | тот же цвет при `opacity:0.5` | то же | незаполненные деления сигнала Wi-Fi, громкости |
| Ошибка, отключено, критично, «занят» | `ColorScheme-NegativeText` | `#f5828a` (245,130,138) | `audio-volume-muted`, батарея `Fill0`/`Fill10`, `network-*-off`, `notifications-disabled`, `plasmavault_error`, `*-quota-critical`, `media-record`, `user-busy` |
| Новое, доступно, активный процесс | `ColorScheme-Highlight` | `#d28cca` (фирменный акцент DARK) | `mail-unread-new`, `network-*-available`, `notification-progress-active`, `update-low`, `user-invisible`, OSD |
| Предупреждение, «отошёл» | `ColorScheme-NeutralText` | `#f68c28` (246,140,40) | `*-limited`, `quota-low`, `update-medium`, `user-away` |
| В сети, питание подключено | `ColorScheme-PositiveText` | `#3cc86e` (60,200,110) | `user-online`, `AcAdapter` |
| «Отошёл надолго», «не в сети» | цвет текста при 0.5 | `#eff0f1` при 0.5 | `user-away-extended`, `user-offline` |
| Знак на цветном круге | `ColorScheme-HighlightedText` / `ColorScheme-Background` | `#31363b` | `preferences-desktop-notification`, батарея `Unavailable` |

Цвета DARK взяты из ролей `ROUNDEDDARK.colors` и дают не меньше 3:1 к фону
панели `#31363b`. Тёмный фирменный `#a22f66` для значков не подходит: на
панели он даёт около 1.7:1. Статусы пользователя различаются не только
цветом, но и бейджем (галочка, часы, стрелка, карандаш, три точки, минус).

Отключённое состояние показывается не только цветом: поверх значка
проводится косая черта (например, перечёркнутый колокол
`notifications-disabled`).

**Правила для новых значков**

- Рисуйте на сетке 22 px с полем 2 px; линия 1 px заливкой, концы
  скруглены, углы корпусов 1.5–2.5 px.
- Добавляйте оба элемента: `22-22-<имя>` и масштабируемый `<имя>`,
  с невидимым прямоугольником холста.
- В COLOR — только классы `ColorScheme-Text`, `Highlight`, `NegativeText`,
  `NeutralText`, `PositiveText`. Никаких фирменных цветов: значок должен
  перекрашиваться вместе с палитрой.
- В DARK — те же формы и цвета из таблицы выше; каждый цвет ≥ 3:1 к
  `#31363b`.
- Цвет — только для состояния: ошибка, предупреждение, новое. Обычное
  состояние монохромное. Отключение дополнительно отмечается чертой или
  формой.
- Значок для приложения добавляйте, только если оно действительно
  показывает его в лотке; иконки меню приложений тема не заменяет.

### 8.2. Типографика и движение

- **Шрифты** тема не задаёт: размеры и начертания берутся из настроек
  системы. Проверяйте изменения при шрифте 14 pt; заголовок окна высотой
  24 px не должен обрезать текст.
- **Иконки приложений** — Breeze / Breeze Dark. Тема их не заменяет;
  исключение — значки лотка из раздела 8.1.
- **Движение.** Единственная анимация темы — плавное появление заставки
  за 1000 ms. Не добавляйте декоративных переходов; если переход нужен,
  он должен объяснять смену состояния и отключаться вместе с глобальными
  анимациями.

## 9. Доступность (пороговые значения)

Критерий проекта — WCAG 2.x AA; подробности и источники в
[README → Usability and Guidelines](../README.md#usability-and-guidelines).

- Значки панели: в COLOR нет жёстких цветов; в DARK каждый цвет
  ≥ 3:1 к фону панели.
- Текст к своему фону ≥ 4.5:1: все роли `Foreground*` (включая
  `ForegroundVisited` и `ForegroundActive`) в группах Window, View,
  Tooltip, Header, Header/Inactive, Complementary и Button, а также
  заголовки окна в `[WM]`.
- Если цвет роли не проходит на одном фоне группы, его светлота меняется
  только в этой группе, оттенок сохраняется (так сделано для группы
  Button в DARK: фон кнопки светлее фона окна).
- Индикатор фокуса и `DecorationFocus` ≥ 3:1 к фону.
- Контур свёрнутой задачи ≥ 3:1 к сплошной панели.
- Состояние не передаётся одним цветом.

`scripts/check-theme.py` (функция `check_usability`) проверяет эти пороги
автоматически. Если меняете цвет, порог должен остаться выполненным;
если меняете сам порог, обоснуйте это в README.

## 10. Известные отклонения

Это не образец для подражания, а места, где тема пока расходится со
своими же правилами.

| Отклонение | Где | Что сделать при следующем изменении |
| --- | --- | --- |
| Запасной акцент в таблицах стилей COLOR — синий Breeze `#3daee9`, а фирменный — фиолетовый | `ROUNDED-COLOR/**/*.svg` | оставить: виден только без палитры |
| Часть виджетов берётся из стиля Plasma по умолчанию (`calendar`, `frame`, `toolbar` и др.) | см. README → Deliberate Fallbacks | при отрисовке своих применять шкалы разделов 3–6 |

## 11. Контрольный список изменения

Перед коммитом:

- [ ] Радиус взят из шкалы раздела 3, вложенный элемент скруглён меньше
      внешнего.
- [ ] В COLOR нет новых жёстких цветов видимых частей, только
      `ColorScheme-*`.
- [ ] В DARK цвета взяты из палитры раздела 4; `colors` и
      `ROUNDEDDARK.colors` совпадают.
- [ ] Покой монохромный; акцент появляется только для фокуса, выделения
      или внимания.
- [ ] Ступени тона возрастают: покой < наведение < нажатие.
- [ ] Фокус — кольцо 2 px акцентом; отличие от других состояний не
      только в цвете.
- [ ] Нет обводок, бликов и новых декоративных градиентов (кроме
      фирменного градиента DARK).
- [ ] Изменение сделано в обоих вариантах, если элемент есть в обоих;
      геометрия и ID совпадают.
- [ ] Проверки проходят:

  ```sh
  sh scripts/check-theme.sh --runtime
  python3 scripts/test-install.py
  ```

- [ ] Превью отрисовано и сравнено с соседними элементами:

  ```sh
  rsvg-convert -z 3 -b '#808080' plasma/desktoptheme/ROUNDED-COLOR/widgets/<file>.svg -o /tmp/preview.png
  ```

- [ ] Тема установлена из ветки и проверена вживую: светлая и тёмная
      палитра для COLOR, DARK, шрифт 14 pt, навигация только с клавиатуры.
      После установки сбросьте кэш SVG (переключите стиль туда и обратно
      или удалите `~/.cache/plasma-svgelements*` и `~/.cache/ksvg-elements*`).
